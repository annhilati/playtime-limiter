PlaytimeLimiter is a highly configurable Minecraft server plugin for limiting the time players can play on a server in some way.

### Some ways one could use this plugin
- to let players only play 3 hours per day
- to give players 3 more hours for playing every day
- to remind players to go touch some grass when playing more than 2 hours in a day
